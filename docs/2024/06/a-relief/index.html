A Relief

12 June 2024

https://poems.culturing.net/2024/06/a-relief/

In the deep,
the time swirls
like Nothing ever,
hurling out new gods
and old beliefs.

It's a relief,
really, after all
the faith, to be
set free, to be
as one is,
as all is.

time · faith · freedom
